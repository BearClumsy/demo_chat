# 2026-09-03

## Phase 3b: Kubernetes deploy layer (kubeadm on EC2) — lint-only skeleton

Pivoted the deploy target from **ECS Fargate** to **self-managed Kubernetes (kubeadm) on EC2**
behind the NGINX Ingress Controller, and wrote out the whole layer as reviewable, CI-linted,
never-applied code. New doc: [[kubernetes]].

### Terraform (`infra/terraform/`)

- **New modules**: `k8s-cluster` (control-plane + worker ASGs, internal API NLB with `/readyz`
  health check, node IAM with Bedrock invoke + ECR pull + cluster-autoscaler perms, KMS key, a
  deploy/snapshot S3 bucket, the `kubectl-apply` / `kubectl-rollback` SSM documents, SSM VPC
  endpoints, `user-data-{controlplane,worker}.sh.tftpl`), `alb-k8s` (internet ALB, `target_type =
  "instance"` on the ingress NodePort 30080, health check on NodePort 30254, 300 s idle +
  deregistration delay for SSE), `ecr` (two repos, scan-on-push, lifecycle), `github-oidc` (GitHub
  OIDC provider + deploy role: ECR push, `secretsmanager:GetSecretValue`, `ssm:SendCommand`
  scoped to the documents + `k8s-role=control-plane` instances).
- **`envs/{staging,prod}` rewired** — drop the `ecs_service` call, add `k8s_cluster` / `alb_k8s` /
  `ecr` / `github_oidc`. New TODO vars: `node_ami_id`, `admin_cidr`, `github_org`,
  `kubernetes_version`. Removed `server_image` / `desired_count` (unused → would trip
  `terraform_unused_declarations`). `task_secret_arns` grew a 4th key, **`CASSANDRA_USER`** —
  Amazon Keyspaces issues a username+password pair and it was missing from the ECS contract
  (flagged in [[2026-08-31]]).
- **`ecs-service`, `alb`, `bedrock-iam` retained** as lint-clean references (each has a README
  saying so); no env instantiates them. `tflint --recursive` still checks them; not gutted so
  `terraform_unused_declarations` stays quiet.
- Kubeadm bootstrap without a designated node: control-plane + worker user-data race on an SSM
  `init-lock` parameter written **without `--overwrite`**; the winner runs `kubeadm init
  --upload-certs` and publishes join commands to SSM SecureString; a systemd timer on each
  control-plane node refreshes the (24 h / 2 h) tokens every 6 h; a second timer snapshots etcd to
  S3. Worker join is gated by an ASG `EC2_INSTANCE_LAUNCHING` lifecycle hook.

### Manifests (`infra/k8s/`)

- `manifest-staging.yaml` / `manifest-prod.yaml` — one consolidated multi-doc file each,
  **deliberately duplicated** (as with `application-{staging,prod}.properties`). Namespace with
  PodSecurity `enforce: restricted`; ConfigMap (keys 1:1 with the Terraform `container_env`);
  Secret with `REPLACE_AT_DEPLOY` **placeholders** (rendered from Secrets Manager at deploy time —
  the placeholder is a fail-fast safety net); server Deployment with `startupProbe` →
  `/actuator/health/readiness` (~300 s budget, the k8s form of the [[2026-08-31]]
  grace-period fix), `livenessProbe` → `/actuator/health/liveness` (no restart storm on a
  downstream outage); two Ingress objects sharing the host (`/` → client, `/api` → server, SSE
  annotations on the API one only); HPA / PDB / NetworkPolicy; a `demo-chat-kb-bootstrap` Job.
- `addons/` — pinned `install.sh` for Calico (VXLAN), metrics-server, ingress-nginx (bare-metal →
  DaemonSet, `externalTrafficPolicy: Local`, NodePorts 30080/30443/30254), aws-node-termination-handler,
  and optional cluster-autoscaler.

### App-side changes (small, enabling)

- `modules/client/Dockerfile` → `nginxinc/nginx-unprivileged:alpine` (uid 101, listens 8080);
  `nginx.conf.template` → `listen 8080` + a `/healthz` location. Lets the namespace run
  `restricted`.
- `modules/server/Dockerfile` → pin uid 10001 (`adduser -u 10001`).
- `KnowledgeBaseIndexer` → `--reindex-and-exit` one-shot mode (seed `support_kb`, then
  `SpringApplication.exit(..., 0)`), for the bootstrap Job — staging/prod keep
  `reindex-on-startup=false`.

### CI

- **`manifests-lint.yml`** — `kubeconform` + `kubectl --dry-run=client` + `shellcheck` (add-on
  script + Terraform-stripped user-data templates) + `actionlint` on the deploy workflows. Mirrors
  `terraform-lint` — no AWS credentials.
- **`deploy-staging.yml`** (push to `main`) / **`deploy-prod.yml`** (tag `v*`,
  `environment: production` approval) — skeletons: OIDC → build/push ECR → render manifest +
  Secret → S3 → `aws ssm send-command` (`kubectl apply` on a control-plane node) → `rollout
  status` → smoke test; prod runs the rollback SSM document on smoke-test failure. CI never opens
  a connection to kube-apiserver. Reference GitHub Environment `vars.*` that only exist post-apply.
- **`Makefile`** — new `k8s-lint`, `k8s-render-{staging,prod}`, `k8s-addons`,
  `k8s-apply-{staging,prod}` (break-glass), `docker-push`.
